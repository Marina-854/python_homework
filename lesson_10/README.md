# Домашнее задание №10: Отчетность в Allure

## Описание проекта

Проект содержит автотесты для медленного калькулятора и интернет-магазина с использованием паттерна Page Object, библиотеки `pytest` и инструмента отчетности `Allure`.

## Структура проекта

```
lesson_10/
├── test_01_calc_allure.py   # Тесты калькулятора с Allure
├── test_02_shop_allure.py   # Тесты магазина с Allure
└── README.md                # Данный файл
```

## Описание базового синтаксиса записи и форматирования

Проект использует следующие технологии и синтаксис:

1. **Python** — основной язык программирования для написания тестов.
2. **Selenium** — библиотека для автоматизации взаимодействия с веб-браузером.
3. **Pytest** — фреймворк для написания и запуска тестов.
4. **Allure** — инструмент для генерации отчетов о выполнении тестов.

### Форматирование кода

- Код форматируется в соответствии с **PEP 8** (стиль написания кода на Python).
- Используются **docstrings** (тройные двойные кавычки `"""..."""`) для документирования методов и функций.
- Для каждого метода указаны **типы параметров** (кроме `self`) через двоеточие, например: `param: int`.
- Для каждого метода указан **тип возвращаемого значения** через стрелку, например: `-> str`.
- Все шаги теста размечаются с помощью `@allure.step` или `with allure.step()` для улучшения читаемости отчетов.
- Тесты размечены декораторами: `@allure.title`, `@allure.description`, `@allure.feature`, `@allure.severity`.

## Установка зависимостей

Для работы проекта необходимо установить библиотеки:

```bash
pip install pytest selenium allure-pytest
```

Для генерации отчетов также требуется установить **Allure Report** — утилиту, которая обрабатывает результаты тестирования и создает HTML-отчет.

### Установка Allure Report на Windows (через Scoop)

```powershell
Set-ExecutionPolicy -ExecutionPolicy RemoteSigned -Scope CurrentUser
Invoke-RestMethod -Uri https://get.scoop.sh | Invoke-Expression
scoop install allure
```

### Установка Allure Report на macOS (через Homebrew)

```bash
/bin/bash -c "$(curl -fsSL https://raw.githubusercontent.com/Homebrew/install/HEAD/install.sh)"
brew install allure
```

### Проверка установки

```bash
allure --version
```

## Инструкция по запуску тестов для формирования отчета Allure

1. Установите необходимые зависимости:

   ```bash
   pip install pytest selenium allure-pytest
   ```

2. Перейдите в корневую папку проекта:

   ```bash
   cd python_homework
   ```

3. Запустите тесты с генерацией отчета Allure:

   ```bash
   python -m pytest lesson_10/ --alluredir=allure-results -v
   ```

   Эта команда запустит все тесты из папки `lesson_10` и сохранит результаты в директорию `allure-results`.

   Флаг `-v` выводит подробную информацию о ходе выполнения тестов.

## Инструкция по просмотру сформированного отчета Allure

### Способ 1: Быстрый просмотр (рекомендуется)

После завершения тестов выполните команду:

```bash
allure serve allure-results
```

Эта команда запустит локальный сервер и **автоматически откроет отчет в браузере** по адресу `http://localhost:xxxx`.

### Способ 2: Генерация статического отчета

1. Сгенерируйте отчет:

   ```bash
   allure generate allure-results -o allure-report
   ```

2. Откройте отчет:

   ```bash
   allure open allure-report
   ```

   Этот способ создает статическую папку с отчетом (`allure-report`), которую можно передать коллегам.

### Что вы увидите в отчете Allure:

- **Overview** — общая статистика: сколько всего тестов запущено, процент успешных тестов, время выполнения.
- **Suites** — список тестов с детализацией по файлам.
- **Features by stories** — группировка тестов по функциональности:
  - **Калькулятор** — тест `test_calculator` (7 + 8 = 15).
  - **Интернет-магазин** — тест `test_shop_flow` (полный цикл покупки).
- **Test body** — пошаговое выполнение теста в виде дерева:
  - Открытие страницы.
  - Установка задержки.
  - Нажатие кнопок.
  - Ожидание результата.
  - Проверка результата.
- **Результат** — успешное выполнение или ошибка с указанием ожидаемого и фактического результата.

## Декораторы Allure, использованные в проекте

| Декоратор | Назначение | Пример |
|-----------|------------|--------|
| `@allure.feature` | Функциональность | `"Калькулятор"`, `"Интернет-магазин"` |
| `@allure.severity` | Уровень критичности | `CRITICAL`, `BLOCKER`, `NORMAL` |
| `@allure.title` | Название теста | `"Вычисление: 7 + 8 = 15"` |
| `@allure.description` | Описание теста | Текстовое описание сценария |
| `@allure.story` | Аннотация/история | `"Арифметические операции"` |
| `@allure.step` | Разметка шагов | `"Открыть страницу калькулятора"` |
